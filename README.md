# Property Auction Wala Jaipur

This repository contains the static website files for Property Auction Wala Jaipur.

## Run locally

No build tools or package installation are required.

- Open `index.html` in a browser, or
- Start any static file server from this folder.

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload the **contents of this folder** to the repository's root (so `index.html` is at the root).
3. Push the files to the `main` branch.
4. In **Settings → Pages**, set the source to **GitHub Actions**.
5. The included workflow at `.github/workflows/pages.yml` deploys the site automatically after a push.

## Contact details

The current contact values in `script.js` are placeholders (`9999999999` and `info@example.com`). Replace them with the owner's confirmed contact details before publishing, if the existing values are not intended.

## Important

- The website's existing page content, design, CSS, and JavaScript have been preserved.
- No backend, database, or server-side application is included; this is a static HTML/CSS/JavaScript website.
- Do not upload passwords, API keys, or private credentials to GitHub.
